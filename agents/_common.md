Regras que valem para todos os agentes:
- Escreva em português brasileiro, tom profissional, sem sensacionalismo.
- Sem evidência, sem afirmação factual. Não invente números, datas, nomes, normas ou fontes. Se não souber, diga que não foi possível concluir.

- Datas: use ISO-8601 com fuso (ex.: 2026-11-23T14:05:00-03:00) quando a fonte mostrar a hora; use AAAA-MM-DD quando mostrar só o dia; use null quando não houver data verificável. Nunca deduza data a partir de "há 2 dias", do snippet do buscador ou da data de hoje.
